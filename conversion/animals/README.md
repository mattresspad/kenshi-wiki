## Reproduction and acceptance

Use scripts/animals/intake.mjs freeze or verify-freeze with the pinned comparison checkout and its extracted reference folder. Transfer the next named batch, run scripts/animals/review.mjs, then npm run animals:accept. A normal production build uses only checked-in FreshWiki files. The source checkout is needed for intake/review evidence extraction, not ordinary builds.

Each acceptance runs the build, catalog/browser suites and Cloudflare prebuilt package dry run; saves route/gap snapshots, link changes and representative light/dark captures at 1440 by 900 and 390 by 844. Every incoming article is checked for page overflow at both widths. Prior Holy Nation citations, Backpacks, ribbon fonts and warm-cache editing regressions remain active.

scripts/gaps/record-resolutions.mjs animals retains closure proofs without relabeling older evidence. scripts/animals/handoff.mjs generates the review gallery, per-batch gap changes, unique/reused counts and Characters reconciliation. The shared searchable report remains at /gaps/ on the local reports server.
