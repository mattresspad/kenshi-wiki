# Geography conversion

The family uses the article registry and the [pinned comparison](https://github.com/mattresspad/kenshi-wiki/tree/83abc179fafa63b826d7f2662c4a18a134a9e6c1). Locations, Zones and Spawning Locations contribute 362 distinct articles. Thirteen towns listed under Old World Towns and seven explicitly named additions bring the roster to 382. Blood Bandit Camp keeps its empty category list. Port South/Empire Peasants keeps Article stubs. The reviewed parent Catun retains its existing section ledger.

[The roster](roster.json) keeps settlements with their overrides. [The reference](reference.json) records ordered heading IDs and labels, citation targets, and fingerprints for prose, link labels and destinations, data cells, units, sort metadata and fact groups. It also records empty Gallery sections and source icon hashes. Markdown and image inputs are checked against the pinned Git blobs. Historical town notices precede their descriptions, and source quotes retain their speaker credits. Other media remain unassessed until someone compares the page with its credited source.

To regenerate the reference, build the pinned comparison in a separate directory, then run `node scripts/geography/intake.mjs freeze <comparison-checkout> <pinned-source-and-build>`. For each next batch, run the same command with `transfer` in place of `freeze` and the roster batch name as its final argument. The normal site build uses only FreshWiki files.

Run `npm run geography:accept` at each checkpoint. It builds the site, compares every transferred geography article against the reference, runs catalog and browser tests, requests a Cloudflare package dry run, and captures the new batch on desktop and phone. The link history starts with the eleven-page preview. Every entry lists destinations introduced or resolved since the preceding batch. The full route and media ledgers, remaining live destinations, screenshots and four command logs go into that batch’s directory under `reports/geography`. Generate the family’s screenshot and exception index with `node scripts/geography/gallery.mjs`. It uses the local per-batch evidence directories. The main report retains credits, source revisions and edit targets independently of transfer and editorial status.
