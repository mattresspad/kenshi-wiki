Kenshi item icons — Lo-Fi Games' artwork

public/icons/items/<string id>.png are item inventory icons. Items the game
draws from their mesh are drawn the same way by MeitouClient's
`meitou-tools icons` (GPL-3.0-or-later, https://github.com/VlcekM/MeitouClient)
from the game's own meshes and textures, matching the renders Kenshi caches in
its data/icons folder; the others are the game's own icon files. Each is named
after the item's string id in the game data, and the article showing it carries
that id in its infobox. scripts/game-items.mjs copies them. The meshes, textures
and icon files are Lo-Fi Games' artwork; Kenshi is a Lo-Fi Games mark.

public/icons/talk.png, the loading screen tip marker, is the 48x32 pic_PointerTalk
frame of Kenshi's UI atlas (data/gui/gfx/Kenshi_UI.png, region defined in
data/gui/images/kenshi_images.xml), cut out unchanged by
scripts/split-ui-atlas.mjs. It is Lo-Fi Games' game artwork; no separate
redistribution permission is recorded here.

Graphics with documented sources

public/images/Checker-16x16.png matches the Wikimedia Commons original.
The file description identifies this simple transparency pattern as public
domain (PD-shape).
https://commons.wikimedia.org/wiki/File:Checker-16x16.png

The 19 files under public/skins/Vector and six under
public/resources/src/mediawiki.skinning match the upstream graphics in the
linked source archive, allowing for SVG line endings. See Vector-COPYING.txt,
MediaWiki-COPYING.txt and MediaWiki-CREDITS.txt in this directory. The archive
keeps the original filenames, editable source, upstream notices and file URLs.

Ribbon files below are in public/ribbon-icons/.
webfcs.svg is the clipboard and magnifier drawn for the wiki's ribbon.
github.svg uses the mark-github geometry from GitHub's Octicons. The original
MIT notice is included as Octicons-MIT.txt. GitHub retains its brand rights.
https://github.com/primer/octicons/blob/v9.6.0/icons/mark-github.svg

Meitou — retained for the project link

The two-moon meitou.webp is a small derivative of the Meitou site's favicon,
selected by the project's creator for this link. A general redistribution
license was not supplied. https://meitou.kenshi.wiki/

Map and KenshiDB — first candidates for original replacements

map.svg and kenshidb.svg use the same path geometry as WebFCS's map-icon.svg
and database-icon.svg. Those source files identify SVG Repo as their source.
The individual artists, item pages and terms remain unconfirmed. Keep the
current glyphs until equivalent original drawings are ready.
https://web-fcs.kenshi.wiki/assets/icons/map-icon.svg

Release history and external references

On 7 November 2026, Outland replaced public/images/Shadow_after.png with a
CSS gradient. The PNG is no longer in the site build. It was introduced in
56200ac and remains in that commit. The image matched the file uploaded by
AcDie to RimWorld Wiki; its file page identifies it as "Copyright game".
No separate redistribution permission is recorded here.
https://rimworldwiki.com/index.php?oldid=107267
https://rimworldwiki.com/wiki/Template:Copyright_game

The imported CSS retains references to EasonPro fonts, RimWorld backgrounds,
and Wikimedia icons for legacy selectors. These URLs are references to
third-party files and do not confer a license to bundle them. The two original
pages and credits page are tested with cross-origin requests blocked.

A public repository would also expose the artwork in older commits.
Git history also contains public/dark.css (since removed) and prior revisions
of global.css with third-party URLs. A URL in a stylesheet is distinct
from a copy of the image in the repository, such as the original shadow.
