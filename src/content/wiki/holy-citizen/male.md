This **Holy Citizen** is more likely to spawn as a male character than the other Holy Citizen. This version also has slightly higher stats, but not by much.

This character can be found alongside the other type of Holy Citizen as a resident in any town controlled by [The Holy Nation](/the-holy-nation). This character can also spawn without a set home in the same locations.
