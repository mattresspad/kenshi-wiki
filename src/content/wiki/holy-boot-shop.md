**Holy Boot Shop** is a shop which sells [Footwear](/footwear) and travel items. This location can potentially sell the blueprint for [Drifter's Boots](/drifters-boots). This vendor is different from the [Boot Shop](/boot-shop) because it only spawns [human](/human) characters and sells fewer items.

### Possible Locations

-   [Blister Hill](/blister-hill)
-   [Stack](/stack)

Depending on certain [World States](/world-states), this vendor might be found in:

-   [Bad Teeth](/bad-teeth)

### Residents

-   [Holy Boot Trader](/holy-boot-trader)
-   [Shop Guard holy](/shop-guard-holy) (1 to 2)
