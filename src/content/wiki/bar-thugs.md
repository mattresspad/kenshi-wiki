**Bar Thugs** is a [faction](/factions) which can only be found in [The Swamp](/the-swamp). Despite there being many different type of bar thug characters in Kenshi, this Bar Thugs "faction" only contains one of them.

## Characters

The only character which can spawn as part of this faction is the [Swamper Bar Thug](/swamper-bar-thug). Swamper Bar Thug is a [randomly named](/random-names-list) character. They are not unique.

## Relations

### Faction Relations

-   [Anti-Slavers](/anti-slavers) (0)
-   [Empire Peasants](/empire-peasants) (0)
-   [Rebel Farmers](/rebel-farmers) (0)

### Player Relations

This faction cannot be allied with, nor is there any dialogue which specifically effects player relations with this faction.
